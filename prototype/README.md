# 画面のプロトタイプ

画面の見た目と操作感を確かめるための、**使い捨ての試作**。API や DB にはつながない。データは仮（架空）で、ブラウザを開き直すと元に戻る。

- 技術：Vue 3 + TypeScript + Vuetify + Vite
- 範囲：一覧、詳細モーダル（検索・絞り込み・並び替え・ドラッグは、まだ作らない）

## 動かし方
```
cd prototype
npm install
npm run dev     # http://localhost:5173 （ポートは固定）
npm run build   # 型チェックとビルド
```

## 仮データについて
日付は「今日」からの日数で決めている。いつ開いても、期限切れ（赤）、3営業日以内（オレンジ）、完了・アーカイブ中（色なし）を確かめられる。
祝日は一部だけ登録している（本番では、日本の祝日を判定するライブラリを使う）。
