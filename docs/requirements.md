# 要件定義

社内業務依頼管理＆作業テンプレートアプリの仕様。ヒアリングで決まったことをまとめる（2026-11-03 時点。依頼者、一覧の列、詳細モーダル、チェックリスト、カテゴリーの削除を追記）。
決まっていないことは、末尾の「未決」に書く。仕様を変えるときは、ユーザーに確認してから、この文書を更新する。

## 1. 目的と使う人
- 他部署からの制作依頼（通関書類、HP、取扱説明書、動画、オフィス移転など）を、1か所で管理する
- 使う人は1人（業務部の担当者）。ログインは、今回は作らない
- 画面は、依頼の**表（一覧）**と、**詳細モーダル**（一覧から開くウィンドウ）で作る。参考：Dribbble の Aivia チケット画面
- サンプルデータは、すべて**架空**（公開リポジトリのため）

## 2. 依頼の項目
| 項目 | 内容 |
|---|---|
| タイトル | 依頼の名前 |
| 詳細 | 依頼の内容（長い文章） |
| 依頼者 | 依頼してきた人。**選択式＋自由入力**（登録済みの人から選ぶ。新しい人は、その場で名前を打てば登録され、次から選べる）。部署は持たない（兼任者が多いため）。**名前**と**内線番号**を登録する（内線番号は空でもよく、あとから足せる）。専用の登録画面は作らず、依頼の入力の中で、その場で直す |
| 受付日 | 依頼を受けた日。**今日が初期値**で、直せる |
| 期限日 | **必須**。空にはできない |
| ステータス | 3 を参照 |
| 確認先 | ステータスが「確認待ち」のときに入力。**選択式＋自由入力**（例：依頼者、薬事部、開発部、営業部） |
| 優先度 | **急ぎ・高・中・低** の4段階 |
| 業務カテゴリー | 通関、HP など。7 を参照 |
| QMS チェック | **チェックボックス**（オン／オフ）。絞り込みに使う |
| アーカイブ | 4 を参照 |

## 3. ステータス
**未着手 → 作業中 → 確認待ち → 完了**、このほかに **ペンディング**（保留）。

- 「確認待ち」は、依頼者や関係部署に確認を頼んで、返事を待っている状態。確認先は、依頼ごとに違う（例：HP は、修正したら依頼者にプレビューの URL をメールで送る。QMS に関わるときは、薬事部・開発部・営業部が多い）
- 一覧から直接ステータスを変えられる（ステータスのラベルを押して、メニューで選ぶ）。「確認待ち」に変えたときは、**確認先を入れる小さな入力欄**が出る。入れずに閉じても、確認待ちにはできる

## 4. アーカイブと削除
- 依頼は、基本的に**消さずに残す**。終わった依頼は「完了」にして、見えなくしたいときは**アーカイブ**する
- アーカイブは、**どのステータスの依頼でも**できる（例：ペンディングのまま、しまいたいとき）
- アーカイブした依頼は、普段の一覧と、検索の結果に出ない。「**アーカイブも表示**」の切り替えで見られて、そこから**元に戻せる**
- **完全に削除**できるのは、**アーカイブ中の依頼だけ**。押すと**確認の画面**を出す。削除すると、その依頼のチェックリストも一緒に消える（元に戻せない）

## 5. 期限の色分け
- 期限が近い・過ぎた依頼を、一覧で目立たせる
  - **期限切れ**：赤
  - **3営業日以内**：オレンジ
- **完了・ペンディング・アーカイブ中**の依頼は、色分けしない
- **営業日**は、土日祝日と、会社の休みを除いて数える
  - 会社の休み：毎年 **12/29〜1/3**（年末年始）と **8/12〜15**（夏休み）
  - 祝日は、日本の祝日を判定するライブラリを使う予定。会社の休みは、**設定ファイル**に書く（画面からは登録しない）

## 6. 検索・絞り込み・並び替え
### 検索
- 対象：**タイトル、詳細、依頼者、確認先**
- アーカイブ中の依頼は、普段は探さない（4 を参照）

### 絞り込み
**QMS チェック**、**業務カテゴリー**、**ステータス** で絞り込む。

### 並び替え
- 最初に開いたときは、**手動の並び**（前回に保存した並び）
- 切り替えられる並び：**優先度**、**期限日**。これは「見せ方」だけで、手動の並びは変えない。手動の並びに戻すボタンを置く
- 新しい依頼は、一覧の**一番上**に入る

### ドラッグ＆ドロップ
- 一覧の行をドラッグして、手動の並びを変えられる。変えた並びは保存する
- ドラッグできるのは、**手動の並びのときだけ**（優先度順・期限日順のときは、できない）

## 6.5 一覧の列と詳細モーダル
### 一覧の列
| 列 | 補足 |
|---|---|
| ドラッグの取っ手 | 手動の並びのときだけ使える |
| 優先度 | 色付きのラベル |
| タイトル | 下に、チェックリストの**進み具合**（例：3/6 完了）を小さく出す。チェックリストがない依頼には、何も出さない |
| カテゴリー | |
| 依頼者 | 名前だけ（内線番号は出さない） |
| ステータス | 押すと変更できる。確認待ちのときは、確認先も添える |
| 期限日 | 色分け（5 を参照） |
| QMS | チェックの印 |

受付日、詳細、内線番号は、一覧には出さず、詳細モーダルだけに出す。

### 詳細モーダルの配置
- **上の段**：タイトル、ステータス、優先度
- **左側（依頼の情報）**：詳細、依頼者（内線番号つき）、カテゴリー、受付日、期限日、確認先、QMS チェック
- **右側（チェックリスト）**：テンプレートを入れるボタン、項目の一覧（チェックを付ける）、項目を足す入力欄
- **下の段**：保存、アーカイブ（アーカイブ中の依頼は、「元に戻す」と「完全に削除」）

## 7. 業務カテゴリーと作業テンプレート
業務カテゴリーごとに、**作業項目のテンプレート**を持つ。依頼にテンプレートを**ワンクリックで入れる**と、作業項目が**チェックリスト**として並ぶ（1件の依頼に、チェックリストが1つ。項目は、複数）。

### 最初に用意するカテゴリー（形だけ。項目は架空のサンプル）
| カテゴリー | 項目の例 |
|---|---|
| 通関 | インボイス、パッキングリスト など |
| HP | （あとで決める） |
| 取扱説明書 | （あとで決める） |
| 動画 | （あとで決める） |
| 引っ越し（オフィス移転） | 見積もり依頼、業者の選定、現状の備品の確認、レイアウト図の作成、各種届出、当日の段取りの確認 |
| 研究倫理委員会 | 出席依頼の受領、会議資料の内容把握、事前問答集の確認と質問決め、会議出席 |

### 編集できること（3つとも、最初の範囲）
1. **テンプレートの編集**：カテゴリーのテンプレートに、作業項目を追加・編集・削除する
2. **依頼のチェックリストの編集**：1件の依頼のチェックリストに、その場で項目を足す（テンプレートは変わらない）
3. **カテゴリーの新規作成**：新しい業務カテゴリーと、そのテンプレートを作る

カテゴリーと項目は、コードに固定せず、**DBのデータ**として持つ。

### チェックリストの項目
- 1項目に持つのは、**項目名**と、**チェックのオン／オフ**だけ（期限・担当・チェックを付けた日は持たない）
- 項目の並び替え（ドラッグ）は、最初は作らない。テンプレートの順番のまま

### カテゴリーの削除と名前の変更
- 依頼が1件でも使っているカテゴリーは、**削除できない**。使っていないカテゴリーだけ削除できる
- カテゴリーの**名前の変更**は、いつでもできる
