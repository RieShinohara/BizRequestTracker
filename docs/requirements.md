# 要件定義書：社内業務依頼管理＆作業テンプレートアプリ

この文書は、要件定義の全体像をまとめた入口である。詳細は、内容ごとに別のドキュメントに分けている。
ヒアリングで決まったことをまとめている（2026-11-03 時点＋プロトタイプで決めたこと）。仕様を変えるときは、ユーザーに確認してから、該当の文書を更新する。

## 1. 目的と使う人
- 他部署からの制作依頼（通関書類、HP、取扱説明書、動画、オフィス移転など）を、1か所で管理する
- 使う人は1人（業務部の担当者）。ログインは、今回は作らない
- 画面は、依頼の**表（一覧）**と、**詳細モーダル**（一覧から開くウィンドウ）で作る。参考：Dribbble の Aivia チケット画面
- サンプルデータは、すべて**架空**（公開リポジトリのため）

## 3. 範囲の概要
- 依頼を、表（一覧）で管理する。ステータスは「未着手・作業中・確認待ち・完了」と「ペンディング」
- 一覧から、ステータスの変更、検索、絞り込み（QMS・カテゴリー・ステータス）、並び替え（手動・優先度・期限日）ができる。手動の並びは、ドラッグ＆ドロップで変える
- 期限が近い・過ぎた依頼を、色で目立たせる（営業日で数える）
- 依頼を押すと、詳細モーダルが開く。業務カテゴリーごとの作業テンプレートをワンクリックで入れて、チェックリストとして使える
- 依頼は消さずに、アーカイブして残す。完全に削除できるのは、アーカイブ中の依頼だけ
- 使う人は1人で、ログインは作らない

## 4. 受け入れ条件（完成の基準）
次の条件を満たしたら、完成とする。

### 依頼の登録・編集
- 依頼を追加でき、新しい依頼は、一覧の一番上に入る
- タイトル、依頼者、期限日のどれかが空のままでは、保存できない
- 受付日の初期値は今日で、直せる
- 優先度（急ぎ・高・中・低）、業務カテゴリー、QMS チェックを設定できる
- 依頼者を、登録済みの人から選べる。新しい名前を打つと、その場で登録され、次から選べる
- 依頼者の内線番号を、空のまま登録でき、あとから足せる
- 依頼を押すと詳細モーダルが開き、内容を変更して保存できる
- ブラウザを閉じて開き直しても、依頼が消えない

### ステータス
- 一覧のステータスのラベルから、直接ステータスを変えられる
- 「確認待ち」に変えると確認先の入力欄が出る。確認先を入れずに閉じても、確認待ちにできる
- 確認先は、選択式＋自由入力で、打った新しい確認先は次から候補に出る
- ステータスを変えると、画面上部の件数がすぐ変わる

### 件数
- 画面上部に、ステータス別の件数（アーカイブ中を除く）が出る
- 「急ぎ」の件数（アーカイブ中と完了を除く）が出て、1件以上のときは濃い赤、0件のときは淡い色になる

### 期限の色分け
- 期限切れの依頼は赤、3営業日以内の依頼はオレンジで表示される
- 完了・ペンディング・アーカイブ中の依頼は、色分けされない
- 営業日の数え方で、土日・日本の祝日・会社の休み（12/29〜1/3、8/12〜15）が除かれる

### 検索・絞り込み・並び替え
- タイトル、詳細、依頼者、確認先で、検索できる
- QMS チェック、業務カテゴリー、ステータスで、絞り込める
- 最初に開いたときは、手動の並び（前回に保存した並び）で表示される
- 優先度順、期限日順、ステータス順に切り替えられ、手動の並びに戻すボタンで戻せる。切り替えても、手動の並びは変わらない
- 同じステータス（同じ優先度、同じ期限日）の依頼どうしは、手動の並びのまま並ぶ
- 手動の並びのとき（検索・絞り込み中を除く）だけ、ドラッグ＆ドロップで並びを変えられる。並びは保存され、開き直しても同じ

### アーカイブと削除
- どのステータスの依頼でも、アーカイブできる
- アーカイブした依頼は、普段の一覧と検索の結果に出ない
- 「アーカイブも表示」で見られて、そこから元に戻せる
- 完全に削除できるのは、アーカイブ中の依頼だけ。削除の前に確認の画面が出て、チェックリストも一緒に消える

### 業務カテゴリーと作業テンプレート
- 最初から、7つのカテゴリーと、それぞれの作業テンプレートが入っている
- 依頼にテンプレートをワンクリックで入れると、チェックリストとして並ぶ（同じ名前の項目は、重ねて入らない）
- チェックリストの項目に、チェックを付けたり外したりできる。一覧のタイトルの下に、進み具合（例：3/6 完了）が出る（チェックリストがない依頼には、何も出ない）
- 1件の依頼のチェックリストに、その場で項目を足せる（テンプレートは変わらない）
- カテゴリーのテンプレートに、作業項目を追加・編集・削除できる
- 新しいカテゴリーを作れる。カテゴリーの名前は、いつでも変えられる
- 依頼が1件でも使っているカテゴリーは、削除できない

### 画面
- 色（ステータス・優先度・基調色）が、決めたとおりに表示される
- 詳細モーダルが、決めた配置（上の段・左側・右側・下の段）で表示される

## 5. 未決（これから決める）
- 引っ越し（オフィス移転）の作業項目（仮のまま。経験したら見直す）
- 確認先の最初の候補（依頼者、薬事部、開発部、営業部、工場）を、どこに置くか。案：設定ファイルに書く（会社の休みと同じ形。Claude のおすすめ）／最初は空で、使った文字だけが候補に出る。API を作るときに決める
