# ユースケース

利用者（担当者）が、目的を達成するまでの操作の流れを定める。
機能の一覧は [機能一覧](functional-requirements.md)、画面の詳細は [画面設計](screen-design.md) を参照。

**「プロトタイプにない」と書いたものは、画面の試作（`prototype/`）にまだ入っていない操作で、要件から書いている。**

| ID | ユースケース |
|---|---|
| UC-1 | 依頼を追加する |
| UC-2 | 依頼の内容を直す（詳細モーダル） |
| UC-3 | ステータスを変える |
| UC-4 | 依頼を検索・絞り込みする |
| UC-5 | 並びを変える |
| UC-6 | 期限が近い依頼を確認する |
| UC-7 | テンプレートからチェックリストを作り、チェックを付ける |
| UC-8 | 依頼のチェックリストに、項目を足す |
| UC-9 | 作業テンプレートを編集する |
| UC-10 | 業務カテゴリーを作る・名前を変える・削除する |
| UC-11 | 依頼をアーカイブする・元に戻す |
| UC-12 | アーカイブ中の依頼を完全に削除する |

## UC-1: 依頼を追加する
- 目的：他部署から受けた制作依頼を、登録する
- 事前条件：一覧が表示されている
- 基本の流れ：
  1. 「新しい依頼」ボタンを押す
  2. 空の詳細モーダルが開く
  3. タイトル、依頼者、カテゴリー、期限日を入力する（必須）。ほかの項目は、必要なものだけ入力する
  4. 「保存」を押す
  5. モーダルが閉じて、新しい依頼が一覧の一番上に入り、画面上部の件数に反映される
- 例外の流れ：
  - タイトル、依頼者、期限日のどれかが空のまま「保存」を押したら、エラーが出て保存されない
  - 「閉じる」を押したら、入力した内容は捨てられ、依頼は作られない
- 補足：
  - 初期値：ステータス＝未着手、優先度＝中、受付日＝今日、QMS チェック＝オフ、カテゴリー＝先頭のカテゴリー
  - 依頼者は、登録済みの人から選ぶか、新しい名前を打つ。新しい名前は、保存したときに登録され、次から選べる。内線番号は、空でもよい
  - 「確認先」は、ステータスが「確認待ち」のときだけ入力できる
  - チェックリストも、このモーダルの中で作れる（UC-7、UC-8）

## UC-2: 依頼の内容を直す（詳細モーダル）
- 目的：依頼の内容（タイトル、詳細、期限日など）を、変更する
- 事前条件：1件以上の依頼が一覧に表示されている
- 基本の流れ：
  1. 一覧の行を押す
  2. 詳細モーダルが開く
  3. 直したい項目を変更する
  4. 「保存」を押す
  5. モーダルが閉じて、変更が一覧に反映される
- 例外の流れ：
  - 必須の項目（タイトル、依頼者、期限日）を空にして「保存」を押したら、エラーが出て保存されない
  - 「閉じる」を押す、または窓の外を押したら、変更は捨てられる
- 補足：
  - 内線番号は、依頼者の項目の隣で直せる（専用の登録画面はない）。直した内線番号は、その依頼者の他の依頼にも反映される
  - チェックリストの変更（チェック、項目の追加・削除）も、「保存」を押して反映される

## UC-3: ステータスを変える
- 目的：作業の進み具合に合わせて、ステータスを変える
- 事前条件：1件以上の依頼が一覧に表示されている
- 基本の流れ：
  1. 一覧で、依頼のステータスのラベルを押す
  2. メニューに、5つのステータス（未着手・作業中・確認待ち・完了・ペンディング）が出る
  3. 変えたいステータスを選ぶ
  4. その場でステータスが変わり、画面上部の件数もすぐ変わる
- 代替の流れ（「確認待ち」を選んだとき）：
  1. 「確認先を入力」の小さな窓が出る
  2. 確認先を選ぶ、または打つ（候補：依頼者、薬事部、開発部、営業部、工場、これまでに入力した確認先）
  3. 「確認待ちにする」を押す
  4. ステータスが確認待ちになり、一覧のステータスの横に、確認先が出る
- 補足：
  - 確認先は、空のままでも、確認待ちにできる
  - 詳細モーダルからも、ステータスを変えられる（UC-2）

## UC-4: 依頼を検索・絞り込みする（プロトタイプにない）
- 目的：目的の依頼を探す
- 事前条件：一覧が表示されている
- 基本の流れ：
  1. 検索の入力欄に、キーワードを入力する
  2. タイトル、詳細、依頼者、確認先のどれかに、キーワードを含む依頼だけが表示される
  3. 必要なら、QMS チェック、業務カテゴリー、ステータスで、さらに絞り込む
- 補足：
  - アーカイブ中の依頼は、普段は検索の対象に入らない。「アーカイブも表示」をオンにすると、表示される
  - 条件をすべて外すと、全件の表示に戻る
  - 検索・絞り込みの間は、ドラッグでの並び替えはできない（手動の並びは、条件を外してから変える）

## UC-5: 並びを変える（プロトタイプにない）
- 目的：依頼を、見たい順に並べる
- 事前条件：2件以上の依頼が一覧に表示されている
- 基本の流れ（見せ方を変える）：
  1. 並び替えの切り替えで、「優先度」「期限日」「ステータス」のどれかを選ぶ
  2. 一覧が、その順に並ぶ（ステータス順は、未着手 → 作業中 → 確認待ち → 完了 → ペンディング）
  3. 「手動の並びに戻す」ボタンを押すと、手動の並びに戻る
- 代替の流れ（手動で並べる）：
  1. 手動の並びのとき、行の左の取っ手をつかんで、動かしたい位置まで運ぶ
  2. 離すと、その位置に入る。並びは保存される
- 補足：
  - 最初に開いたときは、手動の並び（前回に保存した並び）
  - 優先度順・期限日順・ステータス順は「見せ方」だけで、手動の並びは変わらない。同じ優先度（期限日、ステータス）の依頼どうしは、手動の並びのまま
  - ドラッグできるのは、手動の並びのときだけ
  - 新しい依頼は、一覧の一番上に入る

## UC-6: 期限が近い依頼を確認する
- 目的：急いで対応すべき依頼に、気づく
- 事前条件：期限日のある依頼が、一覧に表示されている
- 基本の流れ：
  1. 一覧を開く
  2. 期限切れの依頼は、期限日が赤で表示される。3営業日以内の依頼は、オレンジで表示される
  3. 画面の上で、「急ぎ」の件数と、ステータス別の件数を見る
- 補足：
  - 完了・ペンディング・アーカイブ中の依頼は、色分けされない
  - 営業日は、土日祝日と会社の休み（12/29〜1/3、8/12〜15）を除いて数える
  - 「急ぎ」の件数は、1件以上のとき濃い赤、0件のとき淡い色で出る（アーカイブ中と完了は数えない）

## UC-7: テンプレートからチェックリストを作り、チェックを付ける
- 目的：業務の手順を、漏れなく進める
- 事前条件：詳細モーダルが開いている。依頼のカテゴリーが選ばれている
- 基本の流れ：
  1. 右側の「テンプレートを入れる」ボタンを押す
  2. そのカテゴリーの作業項目が、テンプレートの順番でチェックリストに並ぶ
  3. 作業が終わった項目の、チェックボックスを押す（取り消すときは、もう一度押す）
  4. 「保存」を押す
  5. 一覧のタイトルの下に、進み具合（例：3/6 完了）が出る
- 補足：
  - 1件の依頼に、チェックリストは1つ。項目は、項目名とチェックのオン／オフだけを持つ
  - すでに項目があるときは、残したまま、後ろにテンプレートの項目が足される。**同じ名前の項目は、重ねて入れない**（もう一度ボタンを押しても、項目が増えない）
  - チェックリストのない依頼には、進み具合を出さない
  - 項目の並び替え（ドラッグ）は、最初は作らない

## UC-8: 依頼のチェックリストに、項目を足す
- 目的：その依頼だけに必要な作業を、チェックリストに加える
- 事前条件：詳細モーダルが開いている
- 基本の流れ：
  1. 「項目を足す」の入力欄に、項目名を入力する
  2. Enter キー、または右の「＋」を押す
  3. 項目がチェックリストの最後に足される
  4. 「保存」を押す
- 例外の流れ：
  - 空のまま Enter キーを押したら、何も起きない
- 補足：
  - 足した項目は、その依頼だけに入る（カテゴリーのテンプレートは変わらない）
  - 項目は、右端の「×」で消せる

## UC-9: 作業テンプレートを編集する（プロトタイプにない）
- 目的：カテゴリーの作業項目を、実際の仕事に合わせて直す
- 事前条件：カテゴリーが1つ以上ある
- 基本の流れ：
  1. テンプレートの編集の画面を開き、カテゴリーを選ぶ
  2. そのカテゴリーの作業項目が、順番に表示される
  3. 項目を追加する、名前を直す、または削除する
  4. 変更を保存する
- 補足：
  - すでにある依頼のチェックリストは、変わらない（テンプレートを入れた時点のコピーのため）
  - 次にテンプレートを入れるときから、新しい内容になる

## UC-10: 業務カテゴリーを作る・名前を変える・削除する（プロトタイプにない）
- 目的：新しい種類の業務に対応する
- 事前条件：カテゴリーの管理の画面が開いている
- 基本の流れ（新規作成）：
  1. カテゴリーの名前を入力して、追加する
  2. そのカテゴリーの作業テンプレートを作る（UC-9）
- 代替の流れ：
  - 名前の変更：いつでもできる
  - 削除：使っていないカテゴリーだけ、削除できる
- 例外の流れ：
  - 依頼が1件でも使っているカテゴリーは、削除できない
  - すでにある名前と同じ名前は、使えない（重複なし）
- 補足：最初から、7つのカテゴリー（HP、動画、研究倫理委員会、通関、取扱説明書、AIアカウント発行、引っ越し）が入っている

## UC-11: 依頼をアーカイブする・元に戻す
- 目的：終わった依頼を、普段の一覧から見えなくして、残しておく
- 事前条件：詳細モーダルが開いている（どのステータスでもよい）
- 基本の流れ（アーカイブ）：
  1. 下の段の「アーカイブ」ボタンを押す
  2. モーダルが閉じて、依頼が普段の一覧から消え、画面上部の件数からも外れる
- 代替の流れ（元に戻す）：
  1. 一覧の上の「アーカイブも表示」をオンにする
  2. アーカイブ中の依頼（薄く表示される）を押して、モーダルを開く
  3. 「元に戻す」ボタンを押す
- 補足：
  - アーカイブ中の依頼は、検索の結果にも出ない（「アーカイブも表示」をオンにしたときは除く）
  - アーカイブ中の依頼は、期限の色分けをしない

## UC-12: アーカイブ中の依頼を完全に削除する
- 目的：もう要らない依頼を、完全に消す
- 事前条件：アーカイブ中の依頼の、詳細モーダルが開いている
- 基本の流れ：
  1. 「完全に削除」ボタンを押す
  2. 確認の画面が出る（「元に戻せません」「チェックリストも一緒に消えます」と表示される）
  3. 「削除する」を押す
  4. 依頼とそのチェックリストが消える
- 例外の流れ：
  - 確認の画面で「やめる」を押したら、削除されない
- 補足：アーカイブ中でない依頼には、「完全に削除」のボタンは出ない
