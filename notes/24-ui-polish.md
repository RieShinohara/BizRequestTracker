# 見た目の調整（文字色・フォント・「必須」の色）

## 決めたこと
| 項目 | 決定 | 理由 |
|---|---|---|
| 文字色 | 薄めのグレー（`#4A4A4A`） | 真っ黒が強いので、グレーを混ぜたいという要望。4案（今の黒、`#333333`、青みの `#374151`、`#4A4A4A`）を、画面で見比べて選んだ |
| フォント | Noto Sans JP | 「HP」の横棒が太く見えて違和感がある、という要望。3案（Noto Sans JP、BIZ UDPゴシック、Zen角ゴシック New）を見比べて選んだ |
| モーダルの「必須」 | 基調色（インディゴ）の小さな札 | 他の文字に埋もれていたため。赤は、「急ぎ」とエラーに使っているので避けた |

## 作ったもの
| 場所 | 中身 |
|---|---|
| `frontend/src/main.ts` | テーマの文字色（`on-surface`・`on-background`）と、濃さ（`high-emphasis-opacity`）。フォントの読み込み |
| `frontend/src/styles.css` | 画面全体のフォントの指定 |
| `frontend/src/components/RequestDialog.vue` | 入力欄の名前を、「必須」だけ分けられる形にして、札の見た目を付けた |
| `CREDITS.md` | フォントとアイコンの出典・ライセンス |
| `frontend/package.json` | `@fontsource-variable/noto-sans-jp` を追加 |

## 学んだこと
- **見た目は、「試しの変更」で見比べて決める**：コミットしない比較パネルを作り、クリックで切り替えて見比べた。決まってから、パネルを取り除いて、本実装した。「どれが良いか」は、文章で悩むより、画面で見るほうが早い
- **Vuetify の文字色は、「色」と「濃さ」の掛け算**：標準では、黒に、濃さ 87%（`high-emphasis-opacity`）を掛けている。色を変えるだけだと、予想より薄くなる。濃さを 100% にして、色そのもので決めた
- **フォントは、アプリに同梱する**：Google Fonts から読み込むと、画面を開くたびに、外部へ通信する（公開アプリでは、避けたい）。`@fontsource` は、フォントを npm の部品にしたもので、自分のアプリの中に入る。AWS 上でも、外部に頼らず動く
- **日本語フォントは、小分けにして配る**：日本語は、文字数が多いので、フォントのファイルが大きい。Fontsource は、約120個に分けてあり、画面に出ている文字の分だけを、ブラウザが読み込む（`unicode-range`）。ビルドの出力は大きくなる（約11MB）が、実際に読み込まれるのは、一部だけ
- **可変フォント（variable font）**：1つのファイルで、太さ（100〜900）を連続して変えられる。太さごとにファイルを分けるより、ファイル数が少ない。フォント名は `Noto Sans JP Variable` になる
- **Vuetify の部品の書体は、個別に決まっている**：画面全体に `font-family` を1回書くだけでは、効かない部品がある。全部の要素に指定した（`!important`）。メニューやモーダルは、画面の外側（`.v-overlay-container`）に描かれるので、そちらにも指定が要る。アイコンは、別の書体（`::before`）なので、影響を受けない
- **スロット（`#label`）で、ラベルの一部だけを変える**：`label="依頼者（必須）"` のように、文字列で渡すと、一部だけ見た目を変えられない。ラベルの中身を差し替える仕組み（スロット）で、「必須」だけを `<span>` で包んだ
- **`scoped` の CSS は、スロットの中身にも効く**：親（`RequestDialog`）の `<style scoped>` は、親が書いたスロットの中身にも、効く
- **ライセンスの確認は、推測しない**：アイコンの部品は、`package.json` では Apache-2.0、同梱の `LICENSE` では Pictogrammers Free License と、表記が違っていた。両方を、そのまま `CREDITS.md` に書いた

## 要件にない、私（Claude Code）が決めた点
- 「必須」の札では、かっこ（）を隠して、「必須」だけにした（札のほうが、すっきりするため）
- フォントの候補は、私が選んだ（3案）。比較は、画面上で行った

## 確認が必要なこと
