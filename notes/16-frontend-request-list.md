## 学んだこと
- **期限の色は、API が決めて返す**：プロトタイプでは画面が営業日を計算していたが、本番は API の `due_level`（`overdue`・`soon`・`null`）を見て色を付けるだけ。祝日や会社の休みの計算を、1か所（バックエンド）にまとめられる
- **2つの API は同時に呼ぶ**（`Promise.all`）：一覧と件数は、お互いを待つ必要がないので、同時に取ると待ち時間が短くなる
- **失敗したら例外を投げる**：`checkHealth` は「つながるか」を true/false で返すが、データを取る部品は、失敗したら例外を投げる。呼ぶ側（`App.vue`）が `try/catch` で受けて、画面にエラーを出す。「0件」と「取れなかった」を区別するため
- **日付の曜日は UTC で計算する**：`2026-11-10` のような日付だけの文字列を `new Date(...)` に直すと、タイムゾーンで日がずれることがある。`Date.UTC` を使えば、実行する場所に関係なく、同じ曜日になる
- **Prettier の整形**：長い属性を持つタグは、自動で複数行に直る。手で整えず、`npm run format` に任せる
- **画面の確認用データ**：開発用 DB が空だと、一覧の見た目を確かめられない。架空のデータを API 経由で入れた（コミットしない）。Git Bash の `curl` で日本語を送ると文字化けしたので、Python から送った
